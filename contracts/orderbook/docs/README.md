## 🎯 核心设计原则

### 1. 链上存储和验证
- 合约负责订单的创建、撮合、取消等核心逻辑
- 资产托管和转移由合约安全管理
- 所有状态变更都经过严格验证

### 2. 事件通知
- 所有重要操作都发出事件
- 事件包含完整的索引字段，便于查询
- 客户端通过事件实时同步状态

### 3. 链下索引
- 客户端监听事件，在本地数据库维护订单状态
- 支持复杂的查询、过滤、排序、分页
- 零 gas 消耗，查询速度快

### 4. 批量查询
- 使用 `getOrders()` 批量获取订单详情
- 减少 RPC 调用次数
- 支持数据一致性验证
